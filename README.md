# Personal website starter

A simple, static personal website built with plain HTML and CSS. It has no build step or package dependencies.

## Edit it with Codex

Open this folder in Codex and ask for specific changes, for example:

> Help me personalize this website. First ask me for the information you need, then update the text while keeping the current layout.

You can also edit `index.html` and `styles.css` directly. Replace the sample name, role, location, project descriptions, and contact email before sharing the site.

## Preview it on your computer

From this folder, run:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000> in a browser. Press Control+C in the terminal to stop the server.

## Put it online with GitHub Pages

1. Create a GitHub repository for the site and upload `index.html` and `styles.css` (and this README if you want).
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select the `main` branch and `/ (root)`, and save.
4. GitHub will show the public website URL on the Pages settings screen after publishing.
5. To use a custom domain later, buy a domain from a registrar, add it in the Pages settings, and follow GitHub's DNS instructions at the registrar.

GitHub's publishing and domain instructions: <https://docs.github.com/en/pages/getting-started-with-github-pages>.
